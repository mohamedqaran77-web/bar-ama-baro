# Product Requirements Document – Bar ama Baro MVP

## Vision

Bar ama Baro waa platform waxbarasho oo Af-Soomaali hormuud u tahay, kana caawinaya ardayda, macallimiinta, waalidiinta, dugsiyada, iyo hay'adaha inay helaan waxbarasho tayo leh online.

## MVP Goal

In la bilaabo platform shaqaynaya oo leh:
- Public website
- Mobile app
- Student dashboard
- Teacher dashboard
- Admin dashboard
- Course marketplace
- Video lesson access
- Manual payment verification
- Certificate verification

## User Roles

### Student
- Register/login
- Browse courses
- Enroll in free courses
- Submit payment reference for paid courses
- Watch lessons
- Take quizzes
- Download certificates

### Teacher
- Apply as teacher
- Create course draft
- Add lesson metadata
- View enrolled students
- View earnings placeholder

### Parent
- View linked child progress in later MVP extension

### Admin
- Approve teachers
- Approve courses
- Verify payments
- Manage users
- View reports

## MVP Course Flow

1. Teacher creates course draft.
2. Admin reviews and approves course.
3. Student browses course.
4. Student enrolls or pays.
5. Admin verifies paid course transaction.
6. Student accesses lessons.
7. Student completes course.
8. System issues certificate.
